# あつたまちゃんのおはらじお

にじさんじ・VTuberの公式情報を紹介する、手動試運転中のWebラジオです。

- 公開予定URL: https://namako4696.github.io/myradio/
- 更新: 手動（自動更新・有料APIなし）
- 言語: 日本語
- キャスター: Muse版の3D風あつやきたまごちゃんを使用予定。目・口は付けず、手振り・ポーズ切り替えで感情表現します。
- 現在の character/ 画像はテンプレートの仮素材です。オリジナル画像への差し替えは未完了です。
- 初回の原稿と音声は未作成。公式発表・一次情報に出典を付けて手動制作します。
